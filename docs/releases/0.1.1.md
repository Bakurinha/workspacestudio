# Etapa 0.1.1 — Correção de inicialização e GitHub Pages

## O que foi feito

- Configurado `base: './'` no Vite.
- Criado workflow de deploy do GitHub Pages.
- Corrigidos caminhos do manifest/favicon para funcionamento em subdiretórios.
- Adicionado fallback visível no `index.html` para diagnosticar falha de carregamento.
- Atualizados README, CHANGELOG e versão da aplicação.

## Por que foi feito

Servir diretamente o código-fonte React/TypeScript pelo GitHub Pages não executa a aplicação como um build Vite. O navegador pode não carregar os módulos e exibir apenas uma página branca.

## Arquivos principais modificados

- `vite.config.ts`
- `index.html`
- `.github/workflows/deploy-pages.yml`
- `README.md`
- `CHANGELOG.md`
- `package.json`
- `src/app/App.tsx`

## Como testar

```bash
npm install
npm run build
npm run preview
```

No GitHub Pages, selecionar `GitHub Actions` como origem e fazer push para `main`.

## Impacto

Não altera o modelo de dados nem o IndexedDB. É uma correção de build/publicação e diagnóstico de inicialização.
