# Workspace Studio 0.4.2

## Objetivo

Tornar o OCR útil também durante a leitura do PDF, permitindo selecionar/copiar palavras reconhecidas diretamente sobre a página e localizar conteúdo OCR com o `Ctrl+F` do navegador.

## O que foi feito

- Adicionada uma camada textual OCR invisível no modo Leitura.
- Cada palavra reconhecida permanece no DOM usando as coordenadas normalizadas retornadas pelo Tesseract.
- O texto transparente acompanha a posição da palavra sem alterar visualmente o canvas do PDF.
- Seleção de texto usa o destaque nativo do navegador.
- `Ctrl+F` passa a localizar palavras OCR presentes nas páginas reconhecidas.
- O modo Editar continua usando a camada de caixas clicáveis da v0.4.1, evitando conflito entre seleção de texto e ferramentas gráficas.

## Por que foi feito

A v0.4.1 permitiu substituir visualmente palavras reconhecidas, mas ainda faltava um comportamento básico de documentos pesquisáveis: selecionar, copiar e localizar texto diretamente sobre a página.

## Como testar

1. Abra um PDF.
2. Execute OCR em uma página.
3. Permaneça ou volte para **Modo Leitura**.
4. Arraste o mouse sobre uma palavra reconhecida e copie o conteúdo.
5. Pressione `Ctrl+F` e pesquise por uma palavra reconhecida naquela página.
6. Entre em **Editar** e confirme que a camada selecionável deixa de interferir com as ferramentas e com **Editar texto na página**.

## Impacto

- Nenhuma alteração de schema do IndexedDB.
- Nenhuma alteração no `originalBlob`.
- Nenhum envio adicional de dados para serviços externos.
- A camada pesquisável existe apenas no visualizador; o PDF exportado ainda não recebe uma text layer invisível de OCR.

## Validação

A versão deve ser considerada concluída somente após `npm test`, build TypeScript/Vite e deploy do GitHub Pages concluírem com sucesso no commit final da versão.
