# Workspace Studio v0.3.0

Data: 2026-09-24

## O que foi feito

Esta etapa estabiliza a interação do editor PDF e adiciona OCR local por página.

### Correções de PDF

- A ferramenta **Desenhar** deixou de atualizar o estado React a cada evento bruto de movimento do ponteiro.
- O rascunho do desenho agora é atualizado no máximo uma vez por frame usando `requestAnimationFrame`.
- Pontos muito próximos são ignorados e traços muito longos têm os pontos compactados para evitar crescimento excessivo em memória/IndexedDB.
- **Cobrir** e **Destacar** agora usam seleção real por clique + arraste + soltura.
- A área selecionada é exibida em tempo real antes da operação ser salva.
- `pointercancel` e pointer capture são tratados explicitamente.

### OCR

- Adicionado Tesseract.js 7.0.0.
- OCR disponível por página inclusive em modo Leitura.
- Idiomas iniciais: Português, Inglês e Português + Inglês.
- A página é renderizada por PDF.js em canvas de maior resolução antes do OCR.
- O reconhecimento ocorre em Web Worker no navegador.
- Progresso é mostrado ao usuário.
- Texto, confiança, idioma e data do OCR são persistidos no registro do documento no IndexedDB.
- O resultado pode ser expandido e copiado.

## Por que foi feito

Na v0.2.0 foram identificados dois problemas de usabilidade:

1. desenho livre podia gerar uma quantidade muito alta de atualizações e fazer a página parar de responder;
2. Cobrir/Destacar usavam retângulos de tamanho fixo, tornando difícil selecionar somente o conteúdo desejado.

O OCR também era uma lacuna relevante para PDFs digitalizados ou documentos sem camada de texto.

## Como funciona

### Desenho

O ponteiro continua produzindo eventos normalmente, mas o editor não cria uma renderização React para cada evento. Pontos próximos são descartados e a prévia é sincronizada por frame.

### Cobrir/Destacar

Ao pressionar o ponteiro é armazenado o ponto inicial. Durante o arraste é calculado um retângulo normalizado. Ao soltar, somente uma área acima do tamanho mínimo é persistida como operação PDF.

### OCR

```text
PDF original
   ↓
PDF.js
   ↓
Canvas temporário em maior resolução
   ↓
Tesseract.js / Web Worker
   ↓
Texto reconhecido
   ↓
DocumentRecord.pdfOcr
   ↓
IndexedDB
```

O Tesseract.js não recebe o PDF diretamente. A engine/modelos de idioma podem ser baixados pela biblioteca no primeiro uso, mas o Workspace Studio não envia o documento para um serviço de OCR.

## Como testar

### Desenhar

1. Abra um PDF.
2. Clique em **Editar**.
3. Selecione **Desenhar**.
4. Faça traços curtos e longos por alguns segundos.
5. Confirme que a página continua respondendo.
6. Use Desfazer/Refazer.
7. Exporte e confira o traço no PDF gerado.

### Cobrir/Destacar

1. Selecione **Cobrir** ou **Destacar**.
2. Clique e arraste sobre uma área pequena.
3. Confira a prévia durante o arraste.
4. Solte e confirme que somente a área escolhida foi aplicada.
5. Teste também arrastando da direita para a esquerda e de baixo para cima.

### OCR

1. Abra um PDF com texto digitalizado/imagem.
2. Escolha Português, Inglês ou Português + Inglês.
3. Clique no botão OCR da página.
4. Acompanhe o progresso.
5. Expanda o resultado abaixo da página.
6. Copie o texto.
7. Feche/reabra o documento e confirme que o resultado permanece disponível no IndexedDB.

## Impactos

- Nova dependência: `tesseract.js@7.0.0`.
- O primeiro OCR pode baixar arquivos da engine/modelo de idioma e, portanto, pode ser mais lento.
- OCR consome CPU e memória proporcionalmente à resolução da página.
- Não houve alteração no schema/indexes do Dexie; `pdfOcr` é um campo opcional dentro do objeto `DocumentRecord`, portanto não foi necessária migration do object store.
- O arquivo PDF original continua imutável.
