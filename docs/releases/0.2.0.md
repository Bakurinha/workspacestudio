# Etapa 0.2.0 — Editor básico de PDF

## O que foi feito

- Transformado o visualizador PDF em um editor básico baseado em operações.
- Adicionadas ferramentas de texto, destaque, cobertura branca, desenho e imagem.
- Adicionadas ações de rotação e exclusão de página.
- Criado histórico próprio de PDF com desfazer/refazer.
- Criado `pdfEditService.ts` para intermediar persistência e manter componentes sem acesso direto ao IndexedDB.
- Criado `pdfExport.ts` para reaplicar as operações sobre o arquivo original e gerar uma nova cópia.
- Adicionado teste unitário do exportador.
- Atualizados README, CHANGELOG, versão da aplicação e documentação da etapa.

## Por que foi feito

A v0.1.x permitia somente visualizar PDFs. Isso não atendia ao requisito original do Workspace Studio de possuir funções características de um editor PDF. A v0.2.0 inaugura a camada de edição sem abandonar a regra principal de integridade: o PDF original continua imutável.

## Como funciona

```text
PDF original (Blob imutável)
        ↓
PDF.js renderiza
        ↓
Usuário cria operações
        ↓
IndexedDB persiste operações + cursor
        ↓
pdf-lib reaplica operações no original
        ↓
nome-editado.pdf
```

As operações são independentes do arquivo original. Desfazer/refazer apenas move o cursor das operações ativas.

## Como testar

1. Abrir a aplicação publicada.
2. Importar um PDF.
3. Clicar em **Editar**.
4. Testar Texto, Destacar, Cobrir e Desenhar.
5. Adicionar uma imagem PNG/JPEG.
6. Testar rotação e exclusão de uma página em PDF multipágina.
7. Usar Desfazer/Refazer.
8. Clicar em **Exportar**.
9. Abrir o arquivo `*-editado.pdf` em outro leitor e confirmar as alterações.
10. Confirmar que o arquivo original armazenado continua inalterado.

Validação automatizada:

```bash
npm test
npm run build
```

## Limitações desta etapa

- O texto já existente no PDF não é reescrito semanticamente. Para correções visuais, utiliza-se Cobrir + Texto.
- Rotação é aplicada no arquivo exportado e deve ser preferencialmente realizada após as anotações nesta versão.
- Imagens ainda usam posição/tamanho inicial definidos pelo editor e não possuem arraste/redimensionamento.
- OCR, edição semântica avançada, formulários complexos e assinatura criptográfica não fazem parte desta etapa.
