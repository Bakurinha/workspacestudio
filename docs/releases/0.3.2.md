# Release 0.3.2

## Motivo

Corrigir o colapso visual das páginas PDF observado após a introdução da interface de OCR.

## Causa

O layout utilizava `width: min-content` no bloco da página e `width: fit-content` no frame do canvas. Como o PDF.js define as dimensões do canvas de forma assíncrona, o navegador podia calcular a largura mínima antes do primeiro render e reduzir a página a poucos pixels. O sintoma era uma coluna central contendo praticamente apenas os selos “Página N”.

## Correção

- O editor PDF passou de grid rígido para coluna flexível.
- O visualizador usa `flex` com largura responsiva previsível.
- Cada página recebe largura máxima de 940 px no desktop e ocupa até 100% da área disponível.
- O canvas ocupa 100% do frame mantendo a proporção original.
- Foram removidos `min-content` e `fit-content` do dimensionamento crítico das páginas.
- O código CSS contém comentário explicando por que essa regra não deve ser reintroduzida.

## Impacto

Nenhuma alteração no arquivo original, nas operações de edição ou nos resultados OCR. A correção afeta apenas layout/renderização da visualização PDF.

## Como validar

1. Abrir um PDF com várias páginas.
2. Confirmar que todas as páginas aparecem com largura normal.
3. Alternar Leitura/Edição.
4. Executar OCR em uma página.
5. Confirmar que o canvas não colapsa antes nem depois do OCR.
6. Testar desktop e viewport mobile.
