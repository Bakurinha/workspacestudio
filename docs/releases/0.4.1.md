# Workspace Studio 0.4.1

Data: 2026-09-24

## Objetivo

Corrigir a ambiguidade do OCR editável e permitir que uma palavra reconhecida seja corrigida visualmente diretamente na página do PDF.

## O que mudou

- O Tesseract.js passa a retornar `blocks` além do texto simples.
- Palavras reconhecidas são armazenadas com bounding boxes normalizadas.
- O modo **Editar texto na página** exibe uma camada clicável sobre as palavras reconhecidas.
- Ao selecionar uma palavra, o usuário pode digitar uma correção e usar **Aplicar no PDF**.
- A correção cria uma operação `ocr-replace`, preservando o arquivo original.
- `ocr-replace` cobre a área antiga e redesenha o texto corrigido no mesmo local durante a exportação.
- A transcrição OCR é sincronizada com a palavra corrigida.
- O painel de texto OCR continua disponível para revisão da transcrição completa.

## Como testar

1. Importe um PDF com texto escaneado.
2. Execute OCR em uma página.
3. Ative o modo **Editar** do documento.
4. Clique em **Editar texto na página**.
5. Clique em uma palavra mapeada.
6. Altere o texto e clique em **Aplicar no PDF**.
7. Use Desfazer/Refazer para validar o histórico.
8. Exporte o PDF e confirme a substituição visual.

## Compatibilidade

Resultados OCR salvos antes da v0.4.1 não possuem `words`. Execute o OCR novamente nessas páginas para gerar as coordenadas necessárias.

## Limitações conhecidas

- A substituição é visual e não reescreve o content stream original.
- A fonte de substituição é Helvetica.
- A precisão depende das bounding boxes retornadas pelo OCR.
- Documentos inclinados, desfocados ou com layouts complexos podem exigir ajuste manual com Cobrir + Texto.

## Validação

- Teste de normalização de bounding boxes adicionado.
- Testes existentes de regras, OCR e exportação mantidos.
- Build TypeScript/Vite deve passar antes da publicação do GitHub Pages.
